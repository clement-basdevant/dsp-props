## 1. scipy.signal.lfilter : état final non initialisé sur un bloc vide (bug probable)

Traiter un bloc de longueur 0 avec un état initial `zi` doit renvoyer `zf == zi`.
SciPy 1.18.1 renvoie à la place de la mémoire non initialisée pour un filtre IIR,
et lève une exception pour un filtre FIR. Le traitement par blocs (streaming) devient
faux dès qu'un bloc vide passe, sans aucun message d'erreur.

```python
import numpy as np, scipy.signal as ss
y, zf = ss.lfilter([1.0], [1.0, 0.5, 0.25], np.array([]), zi=np.array([7.0, 8.0]))
print(zf)   # attendu [7. 8.] ; obtenu [4.88e+233 1.85e-286] (valeurs non initialisées)

ss.lfilter([1.0, 2.0], [1.0], np.array([]), zi=np.array([3.0]))
# ValueError: v cannot be empty   (attendu : ([], [3.]))
```

Contre-exemple minimal trouvé par Hypothesis : `x = [1.]`, `b = [1.]`, `a = [1., 0., 0.]`,
découpage `[0]` (un bloc vide puis un bloc de 1 échantillon) : la sortie vaut 4.9e233 au lieu de 1.

Signalé à SciPy le 14 octobre 2026 : [scipy/scipy#26406](https://github.com/scipy/scipy/issues/26406) (couvre aussi le point 2). Corrigé par [scipy/scipy#26415](https://github.com/scipy/scipy/pull/26415), fusionnée le 23 octobre 2026 (SciPy 2.0.0).

## 3. torch.fft (backend MKL) : précision dégradée quand N a un grand facteur premier

L'erreur aller-retour `ifft(fft(x))` de torch reste près de NumPy pour N premier
ou puissance de 2, mais elle est 10 à 100 fois plus grande quand N = petit facteur × grand
premier. Ce n'est pas un résultat faux, mais la borne c · ε · log2 N ne tient plus.

| N | Factorisation | c mesuré, torch | c mesuré, NumPy |
| --- | --- | --- | --- |
| 409 | premier | 0,3 | 0,4 |
| 412 | 4 × 103 | 21,3 | 0,2 |
| 512 | 2^9 | 0,1 | 0,2 |
| 1021 | premier | 0,3 | 0,3 |

(c = ‖ifft(fft(x)) − x‖ / (ε log2 N ‖x‖), maximum sur 20 tirages.) Sur N = 2…1200,
178 longueurs dépassent c = 5 pour torch ; toutes ont un facteur premier ≥ 31.

Conséquence pour la phase 2 : le modèle de tolérance doit dépendre de la factorisation de N
et de l'algorithme (mixed-radix contre Bluestein), pas seulement de log N.
